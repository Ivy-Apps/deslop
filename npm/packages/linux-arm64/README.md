# @ivy-apps/deslop-linux-arm64

Prebuilt `deslop` binary for Linux on arm64.

**You don't need to install this package directly.** It is an optional dependency of
[`@ivy-apps/deslop`](https://www.npmjs.com/package/@ivy-apps/deslop) and npm resolves the
right one for your platform automatically.

```bash
npm install --save-dev @ivy-apps/deslop
```

Deslop is a static import-graph analyzer for TypeScript — you write architecture rules in
YAML and Deslop enforces them on every run. See [deslop.dev](https://deslop.dev) or the
[GitHub repository](https://github.com/Ivy-Apps/deslop).
